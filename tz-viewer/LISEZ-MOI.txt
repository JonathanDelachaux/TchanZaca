INSTALLATION
1. Dézipper TZ-Viewer-1.0-complet.zip.
2. Copier tous les fichiers dans le dossier local du nouveau dépôt TZ-Viewer.
3. Copier les dix médias ci-dessus dans le dossier media.
4. Dans GitHub Desktop : Commit to main, puis Push origin.
5. Sur GitHub : Settings > Pages > Deploy from a branch > main / root > Save.
